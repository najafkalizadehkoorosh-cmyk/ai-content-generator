# AI Router Studio — V1

**وضعیت فعلی: Local-first prototype** — برنامه‌ریز و رابط محلی به Backend پایتون و SQLite وصل شده‌اند. هنوز هیچ مدل هوش مصنوعی یا API خارجی متصل نیست و هیچ Task واقعی اجرا نمی‌شود.

## قابلیت‌های فعلی
- رابط فارسی RTL برای نوشتن درخواست و ساخت Preview
- تشخیص ساده Taskها با قواعد و کلیدواژه‌ها
- تأیید طرح قبل از شبیه‌سازی
- باطل شدن Preview در صورت تغییر ورودی یا تنظیمات
- ذخیرهٔ نسخه‌های Plan، Taskها، وضعیت تأیید و رویدادهای audit در SQLite
- تاریخچهٔ طرح‌های اخیر پس از بازکردن دوبارهٔ برنامه
- API محلی فقط روی `127.0.0.1`، بدون CORS و با بررسی Origin/Host
- اعتبارسنجی ورودی، سقف ۱ مگابایت برای بدنهٔ API و خطاهای JSON ساخت‌یافته
- سیاست fail-closed برای طرح‌هایی که بودجه صفر ندارند یا حالت اجرا را واقعی اعلام می‌کنند
- ابزار پشتیبان‌گیری SQLite با کتابخانهٔ استاندارد پایتون
- بررسی غیرتهاجمی وضعیت Ollama و فهرست مدل‌های محلی از API خود Ollama؛ بدون اجرای مدل یا دانلود جدید
- ۱۱ تست JavaScript و ۱۰ تست Python برای Planner، ذخیره‌سازی، API و بررسی Provider

## شروع در ویندوز
نیاز به Python 3.10 یا جدیدتر دارد؛ هیچ کتابخانهٔ Python اضافی لازم نیست.

1. مخزن را به کامپیوترت دانلود یا clone کن و وارد پوشهٔ `ai-router` شو.
2. روی `start_local.bat` دوبار کلیک کن.
3. مرورگر باید صفحهٔ `http://127.0.0.1:8765` را باز کند. پنجرهٔ سیاه Backend را تا وقتی از برنامه استفاده می‌کنی باز نگه دار.
4. برای توقف، پنجرهٔ Backend را انتخاب کن و `Ctrl+C` بزن.

شروع دستی از ریشهٔ مخزن:

```powershell
py -3 ai-router/backend/server.py
```

اگر فرمان `py` نصب نیست، از `python ai-router/backend/server.py` استفاده کن. سرور فقط به loopback متصل می‌شود؛ برای استفاده از کامپیوترهای دیگر شبکه طراحی نشده است.

## پشتیبان‌گیری
پس از ذخیرهٔ دست‌کم یک Plan، از ریشهٔ مخزن اجرا کن:

```powershell
py -3 ai-router/backend/backup.py
```

پشتیبان در `ai-router/backups/` ایجاد می‌شود؛ این مسیر و دیتابیس محلی در Git نادیده گرفته شده‌اند. برای مسیر سفارشی:

```powershell
py -3 ai-router/backend/backup.py --output "D:\Backups\ai-router.sqlite3"
```

## تست‌ها
با Node.js 24 و Python 3.12 یا نسخه‌های سازگار:

```powershell
node --check ai-router/core.js
node --check ai-router/app.js
node --test ai-router/tests/core.test.cjs
python -m unittest discover -s ai-router/backend -p "test_*.py" -v
```

GitHub Actions همین تست‌ها را روی هر push/PR شاخهٔ کاری اجرا می‌کند.

## محدودیت‌های اعلام‌شده
- بررسی Ollama وجود سرویس/مدل را تشخیص می‌دهد، اما هنوز مدل اجرا نمی‌شود و پاسخ واقعی AI تولید نمی‌شود.
- LiteLLM نصب نشده؛ تا وقتی فقط یک Provider محلی در حال ارزیابی است، افزودن لایه و وابستگی جدید ضروری نیست.
- دکمهٔ تأیید فقط شبیه‌سازی می‌کند؛ وضعیت دیتابیس `simulated` است، نه `succeeded`.
- مسیریابی بر اساس سهمیه، دسترسی منطقه‌ای یا قیمت Providerها هنوز پیاده نشده است.
- تخمین توکن یک heuristic است؛ صرفه‌جویی واقعی اندازه‌گیری نشده است.
- تحقیق وب با استناد، تولید تصویر، Instagram/Meta و انتشار Pages هنوز پیاده نشده‌اند.
- دیتابیس محلی خصوصی و روی همان دستگاه است؛ پوشهٔ data را عمومی نکن.

## سیاست‌های قطعی
1. هزینهٔ پرداختی مجاز: صفر تومان.
2. Provider با هزینه یا سهمیهٔ نامعلوم نباید خودکار اجرا شود.
3. API key و token هرگز داخل Frontend یا Git قرار نمی‌گیرند.
4. تغییر Plan، تأیید قبلی را باطل می‌کند.
5. انتشار عمومی یا حذف داده به تأیید روشن نیاز دارد.
