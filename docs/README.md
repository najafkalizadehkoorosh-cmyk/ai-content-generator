# FitFlow — مربی تمرین خانگی

یک برنامه‌ی ساده‌ی فارسی و راست‌به‌چپ برای انجام تمرین‌های روزانه به‌صورت مرحله‌به‌مرحله.

## امکانات

- انتخاب روز هفته
- نمایش فقط یک حرکت در هر مرحله
- تایمر تمرین و دکمه‌ی پایان حرکت
- رفتن خودکار به حرکت بعدی
- نوار پیشرفت جلسه
- نمایش مقدار تکرار/زمان و استراحت
- ذخیره‌ی پیشرفت در مرورگر با `localStorage`
- طراحی واکنش‌گرا برای موبایل و کامپیوتر

## ساختار

- `index.html` — رابط برنامه
- `style.css` — طراحی و واکنش‌گرایی
- `app.js` — برنامه‌ی تمرینی، تایمر و منطق برنامه

## اجرای آنلاین با GitHub Pages

در تنظیمات مخزن، از مسیر **Settings → Pages**، بخش **Build and deployment** را روی انتشار از یک branch تنظیم کن و پوشه‌ی **`/docs`** را به‌عنوان پوشه‌ی انتشار انتخاب کن. سپس آدرس GitHub Pages نمایش داده می‌شود.

## اجرا روی کامپیوتر

فایل `index.html` داخل همین پوشه را با مرورگر باز کن.
