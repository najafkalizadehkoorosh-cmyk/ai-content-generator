# SafetyVision Offline

نرم‌افزار دسکتاپ ویندوز برای پایش چند دوربین و نمایش عکس رویدادهای مشکوک به نداشتن ماسک یا کلاه ایمنی. پردازش تصویر روی رایانهٔ خودت انجام می‌شود و پس از نصب اولیهٔ مدل، برای تشخیص به اینترنت نیاز ندارد.

## نصب
1. Python 3.11 یا 3.12 نسخهٔ 64 بیتی را نصب کن.
2. فایل install_windows.bat را اجرا کن.
3. در حالی که اینترنت روشن است install_model.bat را یک بار اجرا کن.
4. اینترنت را قطع کن و run_windows.bat را اجرا کن.
5. افزودن دوربین را بزن و شمارهٔ وب‌کم مانند 0 یا آدرس RTSP دوربین IP را وارد کن.

## امکانات
- چند دوربین وب‌کم/IP/RTSP
- تشخیص PPE با کلاس‌های صریح NO-Mask و NO-Hardhat
- نمایش پیش‌نمایش دوربین و عکس نشانه‌گذاری‌شدهٔ هشدار
- ذخیرهٔ زمان، دوربین، اعتماد مدل و تصویر در SQLite و پوشهٔ data
- آستانهٔ اعتماد قابل تغییر و اجرای CPU برای سازگاری با لپ‌تاپ‌های معمولی

## دقت و محدودیت‌ها
این نسخه یک نمونهٔ کاربردی برای آزمایش است و دقت عملیاتی آن تضمین نشده است. مدل پیش‌فرض YOLOv8m برای PPE آموزش دیده، اما عملکردش روی زاویه، نور، فاصله و دوربین‌های محیط شما در این پروژه اندازه‌گیری نشده است. قبل از هر اقدام، هشدار انسانی بررسی شود. برای استفادهٔ جدی باید با تصاویر همان محیط آزمون و اعتبارسنجی انجام شود. پردازش CPU با چند دوربین ممکن است کند باشد.

## حریم خصوصی
عکس‌ها و تاریخچه فقط در پوشهٔ محلی data ذخیره می‌شوند و چیزی آپلود نمی‌شود. هنگام استفاده از دوربین افراد، اطلاع‌رسانی و مجوزهای مربوط به محیط خود را رعایت کن.

## مدل و مجوز
مدل از Hugging Face، مخزن Hexmon/vyra-yolo-ppe-detection دریافت می‌شود. کارت مدل کلاس‌های NO-Hardhat و NO-Mask را معرفی می‌کند و مجوز CC BY 4.0 را برای دادهٔ یادشده نشان می‌دهد. ابزار Ultralytics با AGPL-3.0 و شرایط مجوز مربوطه مرتبط است؛ پیش از استفادهٔ تجاری، مجوز کد و وزن‌های مدل را بررسی کن.
