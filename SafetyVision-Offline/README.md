# SafetyVision Offline

نرم‌افزار دسکتاپ ویندوز برای پایش چند دوربین و نمایش عکس رویدادهای احتمالی نداشتن ماسک یا کلاه ایمنی. تشخیص روی رایانه انجام می‌شود و پس از دریافت بسته، برای کارکرد معمول نیازی به اینترنت ندارد.

## دانلود آمادهٔ ویندوز (بدون نصب پایتون)

از صفحهٔ انتشار نسخهٔ ویندوز فایل **SafetyVision-Windows-x64.zip** را دانلود کن، روی فایل کلیک راست و **Extract All** را بزن، سپس داخل پوشهٔ استخراج‌شده فایل **SafetyVision.exe** را باز کن. مدل تشخیص داخل بسته است. اجرای نخست ممکن است به دلیل آماده‌سازی مدل کمی طول بکشد. برنامه اطلاعات و تصاویر را در پوشهٔ دادهٔ محلی کاربر ذخیره می‌کند.

اگر لینک انتشار هنوز فایل آماده‌ای نشان نمی‌دهد، بخش Releases را دوباره بررسی کن؛ ساخت بسته از طریق GitHub Actions انجام می‌شود.

## شروع استفاده

- برای شروع، برنامه وب‌کم شمارهٔ 0 را خودکار امتحان می‌کند.
- برای افزودن دوربین‌های دیگر، «افزودن دوربین» را بزن و شمارهٔ وب‌کم یا آدرس RTSP معتبر دوربین شبکه (با اطلاعات ورود صحیح) را وارد کن.
- رویدادها و عکس‌های ذخیره‌شده در بخش رویدادهای برنامه نمایش داده می‌شوند.

## اجرای نسخهٔ توسعه‌دهنده از کد منبع

اگر بستهٔ آماده استفاده نشد یا کد را می‌خواهی تغییر بدهی، می‌توانی روش نصب دستی پایین را استفاده کنی:
1. Python 3.11 یا 3.12 نسخهٔ 64 بیتی را نصب کن.
2. فایل `install_windows.bat` را اجرا کن.
3. با اینترنت روشن، `install_model.bat` را یک‌بار اجرا کن.
4. `run_windows.bat` را اجرا کن.

## امکانات

- چند دوربین وب‌کم/IP/RTSP
- هشدار برای کلاس‌های مدل `NO-Mask` و `NO-Hardhat`
- پیش‌نمایش دوربین و عکس نشانه‌گذاری‌شدهٔ رویداد
- ذخیرهٔ زمان، دوربین، میزان اطمینان مدل و تصویر در پایگاه دادهٔ محلی
- تنظیم آستانهٔ اطمینان و اجرای تشخیص روی CPU
- پردازش محلی و بدون آپلود تصاویر

## دقت و محدودیت‌ها

این نرم‌افزار یک ابزار کمکی برای آزمایش است؛ دقت واقعی روی دوربین‌ها، نور، فاصله و شرایط محیط شما هنوز به‌طور مستقل اعتبارسنجی نشده است. هشدارها ممکن است اشتباه باشند یا موردی را از دست بدهند. برای تصمیم‌های مهم ایمنی، فقط به این برنامه تکیه نکن و هشدار را توسط فرد مسئول بررسی کن. پردازش CPU با دوربین‌های متعدد ممکن است کند باشد.

## حریم خصوصی

برنامه تصاویر و تاریخچه را روی همان رایانه نگه می‌دارد و آن‌ها را به سرویس ابری ارسال نمی‌کند. هنگام استفاده از دوربین افراد، اطلاع‌رسانی و مجوزهای محل خود را رعایت کن.

## مدل و مجوزها

مدل از مخزن Hugging Face یعنی `Hexmon/vyra-yolo-ppe-detection` دریافت می‌شود. پیش از استفادهٔ تجاری، شرایط مجوز مدل، وزن‌ها و وابستگی‌ها از جمله Ultralytics را بررسی کن.
