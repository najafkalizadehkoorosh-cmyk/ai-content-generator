# شفارود | فروشگاه اینترنتی

نسخه فرانت‌اند فروشگاه شفارود برای سه دسته برنج، چای و عسل.

## امکانات
- طراحی RTL و واکنش‌گرا
- جستجو، دسته‌بندی، فیلتر و مرتب‌سازی
- سبد خرید با ذخیره‌سازی در مرورگر
- فرم نمونه ثبت سفارش
- پنل مدیریت نمایشی برای افزودن و حذف محصول

> کد 1403 فقط برای نسخه نمایشی است و امنیت واقعی ندارد؛ چون کد در JavaScript سمت کاربر قرار دارد. برای فروشگاه واقعی باید احراز هویت، دیتابیس، مدیریت سفارش و درگاه پرداخت به بک‌اند متصل شوند.

## عکس محصولات
عکس‌های واقعی محصولات شفارود هنوز در مخزن قرار نگرفته‌اند. پس از دریافت عکس‌های واقعی شرکت، می‌توان آن‌ها را در کارت‌ها و صفحه محصول جایگزین کرد.
